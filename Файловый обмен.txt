протоколов для передачи файлов
------------------------------
HTTP и HTTPS — для скачивания файлов через веб-браузер;
SCP — для безопасной передачи через SSH
WebDAV — для совместной работы с файлами через веб
NFS — сетевые файловые системы в средах Unix и Linux
SMB (англ. Server Message Block — «блок серверных сообщений»). Это протокол, который позволяет нескольким компьютерам в одной сети пользоваться 				общими файлами, папками и даже принтерами
FTP (англ. File Transfer Protocol — «протокол передачи файлов»). Он используется для загрузки и скачивания файлов между компьютером и сервером, 				чаще всего через интернет
SFTP - защищенный FTP
