DNS
---

По умолчанию, ОС пытается связать IP с именем сайта. Для этого она обращается к файлу hosts
	Linux - /etc/hosts
	Windows - C:\Windows\System32\drivers\etc\hosts
Если поиск не дал результатов, то запрос передается DNS (настройки TCP/IP)

Виды DNS:
	TLD-серверы (Top-Level Domains) контролируют верхнеуровневые домены. Например .ru, .net, .com и т. д.
	Авторитетных DNS-серверы - частные доменов и их IP-адреса. 
	Рекурсивные DNS-серверы отправляют начальные запросы и полностью контролируют этапы работы DNS-протокола.
	Корневые DNS-серверы (англ. root servers) — это начальная точка для всех DNS-запросов. Они находятся на самом верхнем уровне древовидной системы доменных имён.	

Уровни доменов - это часть доменного имени, отделённая точкой (lessons4.practicum3.yandex2.ru1.0)
 
	Доменами 0-го уровня, они же корневые домены, управляют корневые серверы DNS. Они отвечают на запросы других DNS-серверов в ходе трансляции доменных имён в IP-адреса и	позволяют получить список DNS-серверов для любого домена верхнего уровня. Знают обо всех DNS-серверах верхнего уровня и обо всех зонах, за которые эти сервера 	отвечают
	Домен 1-го (верхнего) уровня (Top-Level Domain, TLD) TLD указывает на глобальную доменную зону, в которой зарегистрирован сайт, будь то страна или тип организации
	Домен 2-го уровня определяет уникальное имя домена, который принадлежит компании или физическому лицу
	Домен 3-го и последующих уровней в большинстве случаев используются как адреса сетевых узлов или сервисов

На DNS-серверах хранится информация о доменных зонах двух типов: 
	DNS-зоны прямого просмотра предназначены для сопоставления доменного имени с IP-адресом.
	DNS-зоны обратного просмотра действуют наоборот, позволяют по IP-адресу узнать доменное имя.


Типы записей DNS
	А-запись (address)  5.5.5.5 TEST.RU
	CNAME-запись (Canonical Name) blog.example.com example.com
	MX-запись (Mail Exchanger) для работы электронной почты
	PTR-запись (Pointer Record) доменное имя для обратного поиска

Настройка DNS клиента:
	
	$sudo nano /etc/resolv.conf  - он отвечает за настройки DNS-клиента
		nameserver 77.88.8.1  /// указываем ip DNS сервера
		search practicumsuperstore.ru  /// указываем 1 и 2 уровень для удосбтва поиска по домену 3 уровня
	$nslookup yandex.ru  - ответ придет от 77.88.8.1

----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------

Установка DNS сервера:
	
	$sudo apt update - обновляем
	$sudo apt-get install dnsmasq net-tools - устанавливаем dnsmasq
	$sudo systemctl status dnsmasq - проверяем 
	$sudo systemctl disable --now systemd-resolved.service - останавливаеи текущий резолд
	$sudo systemctl mask systemd-resolved.service - накладываем маску
		
		///Failed to set DNS configuration: Link lo is loopback device - Это нормально: dnsmasq сообщает, что DNS-сервер сейчас ждёт запросов от клиентов на интерфейсе lo 			(loopback), который недоступен по сети другим устройствам ///
	Все  настройки на DNS-сервере в конфигурационном файле /etc/dnsmasq.conf.
	$sudo nano /etc/dnsmasq.conf
					no-resolv ///не использовать стандартный файл операционной системы resolv.conf,  Вместо этого  dnsmasq
					bind-interfaces ///
					listen-address=10.12.0.5 /// ip сервера DNS --ip a
					interface=eth0 /// интерфейс  --ip a
					server=77.88.8.1 /// DNS ysndex
					server=77.88.8.8 /// DNS ysndex резерв
					cache-size=1000 /// размер кеша
	$sudo systemctl enable --now dnsmasq.service  
	$sudo systemctl restart dnsmasq.service 
	$sudo systemctl status dnsmasq.service

Настройка DNS-записей:

Запрещаем dnsmasq читать записи из /etc/hosts и используем записи, которые внесены в файл /etc/dnsmasq.conf. Чтобы запретить читать записи из /etc/hosts, нужно добавить в конфигурационный файл /etc/dnsmasq.conf  -- no-hosts  

Добавляем А-записи и PTR-records-записи 
	
	$ sudo nano /etc/dnsmasq.conf	

				# A-records		#имя хоста		#IP
				address=/msk-srv-fs.practicumsuperstore.ru/192.168.50.195
				
				#PTR-records            #IP			#имя хоста
				ptr-record=195.50.168.192.in-addr.arpa.,"msk1-src-fs.practicumsuperstore.ru"
