SMB (Server Message Block) — это сетевой протокол, предназначенный для обмена файлами и другими ресурсами в сетях. Он широко используется в операционных системах Windows, но также может быть настроен и использован в Linux-среде
Протокол SMB позволяет пользователям подключаться к удалённым папкам и работать с ними так, будто они находятся на локальном устройстве
--------------------------------------------

1 тачка - сервер
2 тачка - клиент 


$ssh -l <user> <server-ip> - подключаемся 
$sudo nano /etc/hostname - переименуем
$sudo reboot
$sudo apt update
$sudo apt install samba - ставим Samba
$sudo mkdir -p /srv/samba/share - создаем общую директорию
$sudo chown nobody:nogroup /srv/samba/share - задаем владельца
$sudo chmod 0777 /srv/samba/share  - задаем права
$ls -la /srv/samba/share - проверим права доступа 
$sudo nano /etc/samba/smb.conf - нужно отредактировать конфигурационный файл Samba
		///в конец файла///
			[PublicShare]
   			path = /srv/samba/share
   			browseable = yes
   			read only = no
   			guest ok = yes
$sudo systemctl restart smbd
$sudo ufw allow 'Samba' -откройте порт в брандмауэре
		///чтобы закрыть --sudo ufw deny 'Samba'///
$nano /srv/samba/share/downloadme.txt - создадим тестовый файл

	///подключимся с клиента///

$sudo apt update
$sudo apt install smbclient cifs-utils
$smbclient -L //IP_сервера -N -- проверить доступные шары (-N без пароля)
	print$ — это шара по умолчанию, которую Samba использует для обмена драйверами принтеров. Если на сервере настроена поддержка печати, шара 		используется для хранения драйверов, доступных клиентам. Часто она создаётся автоматически.
	PublicShare — это ваша собственная расшаренная папка, которую вы создали и настроили в конфиге smb.conf. Пользователи могут в неё заходить 		и работать с файлами.
	IPC$ (от англ. Inter-Process Communication — «межпроцессное взаимодействие») — это специальная служебная шара. Она используется для 			удалённого администрирования и передачи управляющих сообщений между компьютерами. Содержит именованные каналы, а не обычные файлы. 		Пользователи напрямую с ней не работают.
